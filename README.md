# 🎨 K-Means Explorer

An interactive and visual **K-Means Clustering** application built with **Streamlit**.

This application is designed especially for beginners and design students to understand how K-Means clustering works without requiring prior knowledge of machine learning mathematics.

Students can generate random data points, choose the number of clusters, and visually observe how the centroids move and how the points are grouped over 20 iterations.

---

## ✨ Features

- 🎯 Generate random 2D data points
- 🔢 Choose the number of data points
- 🎨 Choose the number of clusters
- 📍 Automatically select initial centroids
- 🔄 Observe K-Means iteration by iteration
- 🌈 See data points change colour as clusters are formed
- ✖️ Visualize centroid positions
- 🛤️ See the movement path of centroids
- ⏩ Navigate between iterations using a slider
- ◀️ Move to the previous iteration
- ▶️ Move to the next iteration
- 📊 Observe the final cluster formation
- 🖥️ Designed to fit within a single screen for classroom demonstrations
- 🎓 Beginner-friendly explanation of each step
