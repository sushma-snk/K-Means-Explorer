# 🎯 Interactive KNN Classification Lab

An interactive Streamlit application for understanding K-Nearest Neighbours (KNN) classification.

## Features

- Generate random 2D datasets
- Fixed X and Y axes from 0 to 100
- Multiple classes
- Adjustable cluster spread
- Adjustable K value
- Generate a new query point
- Iteration-by-iteration visualization
- K-nearest-neighbour visualization
- Distance lines
- Majority voting
- KNN decision regions
- Previous/Next iteration controls
- Interactive iteration slider
